A simple embroadery PES Brother file viewer, written in Rust for Linux.
- Preview in file loader
- Export to PES 6 and PNG
- 2d view / Embroadery 
- links wires
- Density Slider
- Background color
- Layer to add a file (PES and SVG)
- Resize, Rotate and move layers
- Load SVG
- Edit Curves and stitches points
- PNG loading: opens a "Vectorize bitmap" dialog 
- SVG export of the active layer (with its move/scale/rotate applied).
